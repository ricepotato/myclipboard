# 태그 기능 요구사항

상태: 확정 · 작성일: 2026-10-09

## 1. 개요

각 클립에 여러 개의 태그를 붙이고, 이전에 쓴 태그를 다시 골라 쓰고, 목록 화면에서 태그로 클립을 찾을 수 있게 한다.

## 2. 요구사항

### 2.1 데이터
- **R1.** 한 클립에 태그를 **여러 개** 붙일 수 있다. 클립당 최대 10개.
- **R2.** 사용자가 지금까지 추가한 태그 목록(이하 "태그 목록")을 클립과 **별도로 사용자별로 저장**한다.
  - 저장 위치: Firestore `users/{uid}` 문서.
  - 클립을 모두 불러오지 않아도 전체 태그 목록을 보여줄 수 있어야 한다.
  - 로그아웃/오프라인 상태에서도 쓸 수 있도록 기기에 저장해 두고, 로그인·온라인이 되면 서버와 동기화한다. (기존 클립의 local-first 저장 방식과 같은 원칙)
- **R3.** 이미지 클립에는 태그를 붙이지 않는다. (이미지는 붙여넣는 즉시 저장되고 수정 모드가 없음)

### 2.2 태그 형식
- **R4.** 앞뒤 공백은 제거한다. 공백만 있는 태그는 추가하지 않는다.
- **R5.** 앞에 붙은 `#`은 제거한다. (`#work` → `work`)
- **R6.** 태그 중간의 공백은 허용한다.
- **R7.** 대소문자를 구분하지 않는다. 같은 태그로 취급하되 표기는 처음 입력한 것을 유지한다. (`Work`가 있으면 `work` 입력 시 `Work`가 붙음)
- **R8.** 최대 30자.

### 2.3 입력 화면 (`/`, `/edit/:id`)
- **R9.** 입력 화면(textarea) **아래에 태그 입력 영역**을 둔다.
- **R10.** 태그 입력칸에서 **Enter 또는 `,`** 로 태그를 추가한다. 태그 목록에 없는 새 태그면 태그 목록에도 추가된다.
- **R11.** 태그 입력칸에 **포커스하면 이전에 추가한 태그 목록(후보)** 을 보여준다. 최근 사용순으로 정렬한다.
- **R12.** 글자를 입력하면 후보 중 일치하는 태그만 걸러 보여준다 (**자동완성 검색**). 후보를 골라 붙일 수 있다. 이미 붙은 태그는 후보에서 빠진다.
- **R13.** 붙인 태그는 칩 형태로 표시되고, 칩의 ×로 개별적으로 뗄 수 있다. 입력칸이 비어 있을 때 Backspace를 누르면 마지막 태그를 뗀다.
- **R14.** 태그 입력칸에서도 ⌘/Ctrl+Enter로 저장한다.
- **R15.** 수정 모드에서는 **텍스트가 그대로여도 태그가 바뀌면 저장 버튼이 활성화**된다.
- **R16.** 저장 시 태그도 함께 저장된다. 새 클립 저장 후 수정 모드로 전환될 때 붙인 태그는 화면에 그대로 유지된다.

### 2.4 태그 목록 관리
- **R17.** 자동완성 후보 목록의 각 항목 옆 × 버튼으로 태그를 **삭제**할 수 있다.
- **R18.** 태그를 삭제하면 태그 목록에서 빠질 뿐 아니라 **그 태그가 붙은 모든 클립에서도 제거**한다.
  - 서버 클립과 기기에만 있는(동기화 대기) 클립 모두 대상.
  - 목록 화면의 메모리 목록에도 즉시 반영한다.
  - 지금 입력 화면에 그 태그가 붙어 있으면 화면에서도 뗀다.
  - 되돌릴 수 없는 일괄 수정이므로 삭제 전에 확인 창을 띄운다.

### 2.5 목록 화면 (`/list`)
- **R19.** 각 클립 카드에 붙은 **태그를 표시**한다.
- **R20.** 태그 칩은 표시 전용이다. 칩을 눌러도 카드의 일반 클릭과 같게 동작한다 (텍스트 클립이면 수정 화면으로 이동).
- **R21.** 헤더 아래 검색창에서 **태그 1개를 골라 필터**한다. 검색창도 입력 시 태그 목록에서 자동완성한다. ×로 필터를 해제한다.
- **R22.** 필터 중에도 스크롤하면 해당 태그의 오래된 클립을 계속 불러온다 (서버에서 태그 조건으로 페이지 조회).
- **R23.** 로그아웃 상태에서는 기기에 저장된(동기화 대기) 클립만 대상으로 필터한다.

## 3. Firestore 설정 (콘솔에서 직접 적용)

코드에는 포함하지 않고, 구현 시 필요한 설정을 정리해 전달한다.

- `clips` 복합 색인: `userId` ASC, `status` ASC, `tags` ARRAY_CONTAINS, `createDatetime` DESC
- 보안 규칙: `users/{uid}` 문서를 본인만 읽고 쓸 수 있도록 허용
- 기존 `clips` 규칙이 필드 목록을 제한한다면 `tags` 필드 허용

## 4. 범위 밖

- 태그 이름 변경(rename)
- 여러 태그 조합 검색 (AND/OR)
- 태그 외 검색 (클립 본문 검색)
- 목록 화면에서 직접 태그 편집
- 이미지 클립 태그
